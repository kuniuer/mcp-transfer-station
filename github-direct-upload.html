服务器配置要点

上传接口默认使用当前目录的 ./github_upload.php。服务器端必须配置 GITHUB_TOKEN、GITHUB_REPO=kuniuer/mcp-transfer-station、GITHUB_BRANCH=main；不要把 GitHub Token 写入 HTML。接口应返回 success:true 和 imageUrl，且直链属于 raw.githubusercontent.com/kuniuer/mcp-transfer-station/main/。如果服务器上还没有该 PHP 文件，上传仍不会成功；网页不能替代服务端接口。
二维码内容只使用上传接口实际返回的 GitHub Raw HTTPS 图片直链。当前目标仓库为 kuniuer/mcp-transfer-station；服务端 PHP 的仓库配置也必须同步更新。手机扫码效果仍需通过真实手机网络验收。
